# Profile Audit

A practical X profile review workspace for designers and creators. Review the four parts of a profile that shape a first impression: profile photo, banner, bio and pinned post.

## Features

- Score each profile area against clear design criteria
- Add specific observations and actionable recommendations
- Preview reference screenshots locally in the browser
- Generate and copy a clean client-style audit report
- No API keys, accounts, database or paid AI service required

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

Import this repository into Vercel. The default Next.js build settings are sufficient.

## Important

This first version is a human-led audit workspace. It does not fetch X profiles or claim to analyze screenshots automatically. Profile details and ratings are entered by the reviewer.

## Stack

Next.js, React, TypeScript, Tailwind CSS and Lucide icons.
